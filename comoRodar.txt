PONTO & VIRGULA PAPELARIA
Loja ficticia feita em Django para a aula de Desenvolvimento Web III.

COMO RODAR (PowerShell, dentro da pasta papelaria)

python -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

Depois abra http://127.0.0.1:8000/

LOGIN DE ADMINISTRADOR
Usuario: admin

PAGINAS
/                     inicio
/produtos/            catalogo com busca e filtros
/contato/             formulario de contato
/equipe/              integrantes (Supabase)
/gerenciar/produtos/  adicionar, editar e excluir produtos (so administrador)
/gerenciar/contatos/  mensagens recebidas (so administrador)
/conta/entrar/        login
/conta/cadastro/      criar conta
/api/categorias/      API de categorias
/admin/               admin do Django

SUPABASE (so para a pagina Equipe)
Crie um arquivo .env nesta pasta com:
SUPABASE_URL=https://SEU-PROJETO.supabase.co
SUPABASE_KEY=SUA-CHAVE
A tabela integrantes precisa das colunas id, nome, cargo, biografia e foto_url.
No plano gratis o projeto pausa depois de um tempo parado: confira se ele esta ativo antes de apresentar.
O resto do site funciona sem o Supabase.
